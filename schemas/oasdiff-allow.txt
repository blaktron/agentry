# One-time exception to the additive-only rule: the server keeps no
# credentials of its own. The register, password sign-in and TOTP
# operations leave the server, the sign-in provider id names only the
# deployment's one OpenID provider, and a sign-in's answer no longer carries
# a pending second-factor challenge. CI's oasdiff job ignores exactly these
# while this file exists.
