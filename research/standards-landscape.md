# Agent Registry Landscape Brief — researched 2026-08-27

## 1. Official MCP Registry

- **Status: still preview, not GA.** Launched in preview 2025-09-08; an "API freeze (v0.1)" was declared 2025-10-24 (no breaking changes while validating toward GA). The live docs page still says "currently in preview. Breaking changes or data resets may occur before general availability" as of today. No GA announcement found through the blog's latest post (2026-08-22, "The New MCP Roadmap"). Sources: https://blog.modelcontextprotocol.io/posts/2025-09-08-mcp-registry-preview/, https://modelcontextprotocol.io/registry/about, https://github.com/modelcontextprotocol/registry
- Backed by Anthropic, GitHub, PulseMCP, Microsoft. MCP SDK downloads are "close to half-a-billion a month" per the 2026-07-28 spec post (https://blog.modelcontextprotocol.io/).
- **server.json** (schema `2025-12-11`): `name` (reverse-DNS, e.g. `io.github.user/server`), `title`, `description`, `version`, `websiteUrl`, `repository` (+`subfolder`), `packages[]` (npm/PyPI/NuGet/cargo/OCI/mcpb; each with `transport` = stdio/streamable-http/sse, `runtimeHint` (npx/uvx/dnx), `packageArguments`, `environmentVariables` with secret flag), `remotes[]` (hosted endpoints), `_meta` for namespaced publisher extensions. Source: https://github.com/modelcontextprotocol/registry/blob/main/docs/reference/server-json/generic-server-json.md
- **API style:** REST with a published OpenAPI spec that other registries are encouraged to implement; designed to be consumed by downstream aggregators polling ~hourly, not by end-user clients directly.
- **Security stance: metadata-only.** Namespace authentication (GitHub OAuth/OIDC; DNS/HTTP challenge for domains); it **explicitly delegates security scanning** to package registries (npm, PyPI, Docker Hub) and downstream aggregators; moderation = manual takedowns per a moderation policy, character limits/regex validation, with rate limiting and AI spam detection only "under consideration." Source: https://modelcontextprotocol.io/registry/about

## 2. Anthropic packaging formats

- **Claude Code plugins** — `plugin.json` in `.claude-plugin/`: `name` (required), `version` (drives update checks), `description`, `author`, `homepage`, `repository`, `license`, `keywords` (package.json-like). Plugins bundle commands, agents, skills, hooks, and MCP servers. **`marketplace.json`** is a catalog (`name`, `owner`, `plugins[]`), each entry = plugin-manifest fields (all optional) plus `source` (git/GitHub/path, pinnable to a commit `sha`), `category`, `tags`, `strict`. Docs: https://code.claude.com/docs/en/plugin-marketplaces
- **Agent Skills** — `SKILL.md` with YAML frontmatter. Required: `name` (≤64 chars, lowercase/digits/hyphens, must match directory name), `description` (≤1024 chars, "what + when"). Optional: `license`, `compatibility` (≤500 chars), `metadata` (free string map — where author/version live), `allowed-tools` (experimental). Progressive disclosure model (~100-token metadata → body → `scripts/`, `references/`, `assets/` on demand); reference validator `skills-ref`. Open spec published at https://agentskills.io/specification (repo github.com/agentskills/agentskills; Anthropic-initiated — governance arrangement UNVERIFIED).
- **Marketplaces:** `anthropics/claude-plugins-official` launched 2026-05-22 — Anthropic-managed directory, 55+ plugins at launch, split into Anthropic-built `/plugins` and partner `/external_plugins` (GitHub, GitLab, Linear, Asana, Firebase, Playwright, Terraform, Discord); submissions via form must meet "quality and security standards" (review depth undocumented). Anthropic warns community plugins "may install unverified, third party software." De-facto third-party hubs (claudepluginhub.com, mcpmarket.com, etc.) have no consistent review. Sources: https://github.com/anthropics/claude-plugins-official, https://www.techtimes.com/articles/317139/20260525/claude-code-plugins-get-official-directory-anthropic-flags-unverified-mcp-risks.htm

## 3. AGENTS.md

- Plain-markdown "README for agents"; no required fields. Spec/site: https://agents.md/
- Adoption per the site: "over 60k open-source projects"; 20+ compatible tools including OpenAI Codex, Google Jules, Cursor, VS Code/Copilot, JetBrains Junie; Claude Code also reads it (per third-party guides).
- Governance: emerged from OpenAI Codex, Amp, Google Jules, Cursor, Factory; the site states it is "now stewarded by the Agentic AI Foundation under the Linux Foundation." (Original repo was openai/agents.md; current repo home UNVERIFIED.)

## 4. Google A2A protocol / Agent Cards

- Google donated A2A to the **Linux Foundation** in June 2025 (https://developers.googleblog.com/en/google-cloud-donates-a2a-to-linux-foundation/). LF press release 2026-04-09: 150+ organizations (AWS, Cisco, Google, IBM, Microsoft, Salesforce, SAP, ServiceNow), 22k+ GitHub stars, 5 production SDKs; **v1.0 released within the first year**, introducing **signed Agent Cards** for cryptographic identity verification, plus the AP2 payments extension (60+ orgs). Source: https://www.linuxfoundation.org/press/a2a-protocol-surpasses-150-organizations-lands-in-major-cloud-platforms-and-sees-enterprise-production-use-in-first-year
- Agent Card = JSON self-description (identity, skills, endpoint, auth) served from a well-known URL.
- **No authoritative public Agent Card registry exists**: the LF release lists registry "consolidation of efforts" as roadmap, not shipped. Practice today is internal enterprise catalogs accepting only signed cards; community directories exist but none are official (UNVERIFIED which are active/credible).

## 5. Competing/adjacent marketplaces (2026)

- **Smithery** — MCP registry + hosted deployment (~7,300+ tools); CLI publishing; go-from-found-to-running hosting is the model. Curation depth limited; business model beyond hosting UNVERIFIED. (https://mcpize.com/alternatives)
- **mcp.so** — largest-breadth directory/"store"; light vetting, breadth over curation. Revenue model UNVERIFIED.
- **PulseMCP** — hand-curated directory (~7,000 servers), human review + newsletter; also a named backer of the official registry.
- **Glama** — 12,600+ servers; differentiates on **automated security scans** and quality scoring of listings. (https://designrevision.com/blog/best-mcp-marketplaces-and-registries)
- **Docker MCP Catalog/Toolkit** — curated containerized servers in Docker Hub; PR-based submission with automated tests + human reviewer gate; build attestations, source provenance, **signed SBOMs**, runtime `--verify-signatures`; monetizes Docker Desktop/Hub pull-through. (https://docs.docker.com/ai/mcp-catalog-and-toolkit/faqs/, https://www.docker.com/blog/introducing-docker-mcp-catalog-and-toolkit/)
- **OpenAI** — GPT Store (2024) eclipsed by the **Apps SDK** (MCP-based, DevDay Oct 2025): third-party app submissions with human review via the developer platform and an in-ChatGPT **App Directory** since Dec 2025; monetization limited to physical-goods link-outs so far. (https://openai.com/index/developers-can-now-submit-apps-to-chatgpt/)
- **Enterprise entrants:** Salesforce AgentExchange (Mar 2025, 200+ vetted partners), Google Cloud AI Agent Marketplace (Apr 2025, pre-vetted partner agents), AWS Marketplace "AI Agents & Tools" category (Jul 2025). (https://cloud.google.com/blog/topics/partners/google-cloud-ai-agent-marketplace)
- **New in 2026:** anthropics/claude-plugins-official (May 2026, above); **ClawHub** — community skills marketplace for the OpenClaw agent platform, now VirusTotal-screened after the ClawHavoc incident (below).

## 6. Malicious-agent/MCP/skill incidents, 2025–2026

- **postmark-mcp backdoor** (first documented malicious MCP server; malicious v1.0.16 published 2025-09-17, disclosed by Koi Security): impersonated Postmark; after 15 clean versions, one added line BCC'd every outgoing email to an attacker address; ~1,600 downloads, est. ~300 orgs. **Would-have-caught:** per-release diff scanning for new outbound recipients/endpoints; brand-impersonation/namespace checks. (https://www.koi.ai/blog/postmark-mcp-npm-malicious-backdoor-email-theft, https://thehackernews.com/2025/09/first-malicious-mcp-server-found.html)
- **Shai-Hulud npm worm** (wave 1: 2025-09-16, 187 packages incl. CrowdStrike-related; wave 2: 2025-11-24, ~500–640 packages incl. Zapier, Postman, AsyncAPI, PostHog, ENS — 132M monthly downloads): self-replicating post-install payload runs TruffleHog, steals npm/GitHub/cloud creds, republishes itself, dumps secrets to public GitHub repos. **Catch:** install-script diffing, sandboxed-install egress monitoring, anomalous-publish detection. (https://www.esentire.com/security-advisories/new-npm-supply-chain-attack-identified-second-wave-of-shai-hulud, https://securitylabs.datadoghq.com/articles/shai-hulud-2.0-npm-worm/)
- **GlassWorm** (2025-10-17 onward, waves into Nov; OpenVSX + VS Code marketplace): first self-propagating worm in editor extensions; payload hidden with **invisible Unicode**; Solana blockchain C2; ~35,800 downloads; stole GitHub/npm/OpenVSX creds + crypto wallets and used them to infect more extensions. **Catch:** invisible/bidi-Unicode detection (trivial static check), obfuscation scoring. (https://www.koi.ai/blog/glassworm-first-self-propagating-worm-using-invisible-code-hits-openvsx-marketplace)
- **Amazon Q Developer VS Code extension wiper prompt** (PR merged ~2025-07-13, shipped in official v1.84.0 on 2025-07-17 to ~1M installs): attacker with granted repo access injected a natural-language prompt instructing the agent to wipe filesystem and cloud resources; payload malformed, no confirmed damage. **Catch:** prompt-injection linting of embedded agent instructions; release-diff review; contributor-privilege anomaly checks. (https://www.bleepingcomputer.com/news/security/amazon-ai-coding-agent-hacked-to-inject-data-wiping-commands/)
- **Nx "s1ngularity"** (2025-08-26): stolen npm token published malicious nx versions; malware **weaponized locally installed AI CLIs (Claude Code, Gemini, Amazon Q) for credential reconnaissance**, exfiltrating to 1,400+ public repos. **Catch:** publish provenance/attestation (token-only publishes flagged), postinstall sandbox behavior analysis. (https://www.wiz.io/blog/s1ngularity-supply-chain-attack, https://nx.dev/blog/s1ngularity-postmortem)
- **ClawHavoc — malicious ClawHub skills** (disclosed by Koi Security 2026-02-01; by 2026-02-05 Antiy counted **1,184 malicious skills from 12 accounts**, one account publishing 677): fake crypto/productivity skills on OpenClaw's marketplace delivered Atomic macOS Stealer and C2 backdoors, plus novel agentic fraud (affiliate injection, front-running). ClawHub added VirusTotal screening; evasive skills still got through afterward. **Catch:** pre-publication AV **plus** instruction-content analysis, publisher reputation/rate limits, mass-upload anomaly detection. (https://cybersecuritynews.com/clawhavoc-poisoned-openclaws-clawhub/, https://www.trendmicro.com/en_us/research/26/b/openclaw-skills-used-to-distribute-atomic-macos-stealer.html, https://unit42.paloaltonetworks.com/openclaw-ai-supply-chain-risk/)

## 7. Implications for our registry

- The official MCP registry is deliberately metadata-only and **delegates security scanning to downstream aggregators** — pre-publication scanning is exactly the sanctioned gap; implementing its OpenAPI interface makes us consumable by existing MCP clients.
- Namespace/identity verification (OAuth, DNS challenge) is table stakes everywhere; postmark-mcp shows we also need brand-impersonation detection beyond ownership checks.
- Every marquee incident was a **clean project turning malicious in one release** — per-version diff scanning ("rug pull" detection) beats point-in-time scanning, and git hosting gives us the full history to do it natively.
- Scan the natural-language layer, not just code: SKILL.md bodies, AGENTS.md, and plugin prompts are executable instructions — invisible-Unicode and prompt-injection linting are cheap checks that GlassWorm and Amazon Q would have failed.
- Publisher-behavior signals (account age, mass-upload rates, publish provenance) were structurally sufficient to catch ClawHavoc (1,184 skills, 12 accounts) and s1ngularity; AV-only screening (ClawHub + VirusTotal) demonstrably was not.
- Support the small-manifest formats as first-class citizens — server.json, plugin.json/marketplace.json, SKILL.md, AGENTS.md, A2A Agent Cards — and differentiate with signed provenance (Docker-style attestations; A2A v1.0's signed cards show the direction).
- The competitive lane is open: existing MCP directories are breadth-first (mcp.so), manual (PulseMCP), or platform-locked (Docker, Anthropic's official dir); none combine git hosting + automated pre-publication security review for *agents* specifically.
- No authoritative public A2A Agent Card registry exists yet (LF calls it roadmap) — early standards alignment there is a differentiation opportunity.
