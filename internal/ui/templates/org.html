Policy

Organization policy may only tighten the platform baseline. The server refuses a document that loosens maxAutoPublishSeverity, wildcardEgress or requireHumanReview; every other key it keeps at the stricter of the two values. This page does not show the baseline; read it at GET /api/v1/platform/policy.

The server reads these keys: requireHumanReview, blockedCapabilities, blockedMcpServers, allowedLicenses, maxAutoPublishSeverity, requireEvals, wildcardEgress. It stores any other key and shows it here, but never enforces it.

OIDC

Each form shows what is stored: the SAML metadata, the OIDC issuer and client id, and whether the connection is enabled. The client secret is never shown; leave it blank to keep the stored one, and remove the connection to drop it. Test reports the probe's verdict here.

Your IdP fetches this organization's SP metadata from /api/v1/orgs/<handle>/sso/saml/metadata. Test checks the stored configuration and the IdP's discovery document; it never sends the client secret.
